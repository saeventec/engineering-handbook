# Engineering Handbook

Short, simple lessons on software engineering, learned step by step with AI.
It's my personal knowledge base, but anyone is welcome to read it.

## How it's organized

- **Tier 1 · Core**: the essentials, used almost every day.
- **Tier 2 · Growth**: deeper skills for growing as an engineer.
- **Tier 3 · Awareness**: know it exists and when it matters.

The plan is in [ROADMAP.md](ROADMAP.md). Progress is in [PROGRESS.md](PROGRESS.md).

## How to use it

Open the repo with any AI assistant that can read and write files, and just talk:
start a lesson, ask questions, finish it. You can also look up any topic or bookmark lessons.

The AI follows [AGENTS.md](AGENTS.md). Everything is saved in the files, so you can continue anywhere, with any AI.
